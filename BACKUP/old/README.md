# Archived implementations

Nothing in this folder is built, tested or supported. It is kept for history.

- `csharp-2025/` — the C#/.NET 10 solution (`PrivacyEnforcerPro.sln`) that preceded the
  Rust rewrite, together with its README, validation checklist, CI workflow and `.gitignore`.
  Its backup-file format is still readable by the current tool.
- `pef_devver.ps1` — the original PowerShell script.
- `1.txt` — an empty placeholder from the earliest commits.

The single-file C# console version that came between the two lives one level up in
`BACKUP/Program.cs` with its own README. Do not run any of these on a machine you care about.
